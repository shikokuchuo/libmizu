Detailed Description

Batch-sizing state: process-private, never wire state, reset at each run's first-call CLAIM CAS.

The binding embeds one per map context; a doorbell help that claims a queued runner of the same map aliases it (the cost is a mis-sized batch or a re-ramp on resume — harmless).
