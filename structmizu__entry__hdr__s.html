Detailed Description

Injection ring / deque entry header; payload framing at offset 24, payload bytes at 40.

flags bit 0 is MIZU_ENTRY_RUNNER; bits 1-2 are reserved for a future language tag (homogeneous pools in v1). rs_seq binds the entry to its result slot's incarnation (the sequence at submit): a claimed entry whose stamp no longer matches the slot is a zombie left by a dead claimant and never executes.
