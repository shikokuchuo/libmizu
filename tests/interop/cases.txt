# The golden conformance cases for the 'I' interchange stream (DESIGN.md's
# Interchange codec section is the authority). One case per line:
#   id | kind | langs | value | note
# kinds: rt (bytes <-> value, both directions — every listed binding's home
# is exact), dec (wire => home — the read half where a home shifts), enc
# (value -> hex — the write half), read-err (hex or notation -> the
# informative error; notes start "cursor:" or "builder:"), write-decline
# (value -> the send-time decline; no corpus entry). langs: all, R, PY.
# tools/interop_corpus.py regenerates tests/interop/corpus.txt from this
# file — edit here, never there. A string literal never contains " => ".
