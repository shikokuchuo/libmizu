uint64_t mizu_pool_hdr_s::worker_ident

The workers' identity word (MIZU_IDENT in mizu_ext.h): 0 until the first worker join CASes its binding's word in; a join whose word differs fails, an exact match proceeds.

Set for the pool's lifetime — never reset, so homogeneity is per pool, not per worker generation. The one field written after create: read it through the mapping, never the validated handle copy, which is stale the moment it lands.
